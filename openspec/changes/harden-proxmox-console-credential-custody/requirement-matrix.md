## Release and demo gates

- The staged fixed snapshot must pass a new Codex Security diff scan. The prior
  scan findings are not acceptance evidence for the remediated snapshot.
- Database migrations and source-scope guards must pass in an isolated CNPG
  database, including two identical native identity sets from distinct source
  scopes.
- Compatible control-plane, agent, and first-party plugin versions must be
  deployed before authenticated Proxmox assignments are enabled.
- The farm01 and tonka01 canaries must record immutable source IDs, exact owner
  and controller origins, negative authorization evidence, and redacted audit
  correlation IDs without recording credentials.
- All Ansible provisioning canaries after the original Windows bootstrap must
  originate in ServiceRadar, not directly in AWX.
